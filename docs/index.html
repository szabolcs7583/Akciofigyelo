🔔 Magyar Akciófigyelő

Legalább 50%-os magyar webshop-akciók figyelése. Az automatikus keresés és értesítésküldés még külön beállítást igényel.

1. Nyisd meg az oldalt Androidon Chrome-ban.

2. Másold ide a Firebase Console → Project settings → Cloud Messaging → Web Push certificates alatt látható nyilvános kulcsot.

Még nincs regisztrálva.

Az értesítés engedélyezése után az eszköz Firebase-regisztrációs tokent kap. Ezt ne tedd nyilvános GitHub-fájlba, és ne oszd meg képernyőképen. A tényleges automatikus akcióértesítésekhez biztonságos szerveroldali küldést kell még beállítani.

Eszköztoken megjelenítése (csak saját használatra)
